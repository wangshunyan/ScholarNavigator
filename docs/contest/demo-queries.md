# 赛题三演示查询集

这些查询用于演示和人工检查，不替代 AutoScholarQuery 正式评测。

## 推荐演示查询

1. Find papers after 2022 that use retrieval-augmented generation for multi-hop question answering and report results on HotpotQA.
2. Search for graph neural network papers on molecular property prediction that evaluate on MoleculeNet and exclude review papers.
3. 找 2021 年以后关于扩散模型用于医学图像分割的论文，要求结果里说明数据集和评价指标。
4. Find papers about long-context language model evaluation that compare retrieval-based methods with full-context inference.
5. 搜索使用强化学习优化大语言模型推理路径的论文，优先返回有代码或开源数据的工作。
6. Find survey-free papers on federated learning for non-IID medical data with experiments on real clinical datasets.
7. 查找 NeurIPS 或 ICLR 中关于 test-time adaptation 的论文，排除纯综述，关注图像分类任务。
8. Find recent papers that combine knowledge graphs and large language models for biomedical question answering.
9. 搜索关于自动学术论文检索智能体的论文，要求涉及查询改写、迭代搜索或相关性判断。
10. Find papers on contrastive learning for recommender systems that evaluate on Amazon or MovieLens datasets.
11. 找 2020 年以后使用 Transformer 进行时间序列异常检测的论文，并说明是否使用公开数据集。
12. Find papers about efficient fine-tuning of large language models for code generation, excluding prompt-only methods.
13. 搜索多模态大模型在遥感影像理解中的应用，优先包含目标检测或语义分割实验。
14. Find papers that use causal inference to improve out-of-distribution generalization in machine learning.
15. 查找关于隐私保护检索增强生成的论文，重点关注数据泄露、防御或审计方法。
16. Find papers on neural information retrieval that use dense retrievers and evaluate on BEIR.
17. 搜索小样本医学文本分类中的 prompt tuning 或 parameter-efficient tuning 论文。
18. Find papers after 2023 on agentic scientific discovery systems that include benchmark evaluation.
19. 查找自动驾驶场景中多传感器融合的深度学习论文，要求包含 nuScenes 或 Waymo 数据集。
20. Find papers on citation graph-based paper recommendation that combine content and graph structure.

## 录屏建议

- 选 3 到 5 条覆盖不同约束的查询即可，不要把演示视频做成批量测试。
- 每条查询展示输入约束、检索进度、排序结果、引用关系图和导出。
- 录屏中不要出现 API key、学校/导师/队员信息或本地敏感路径。
